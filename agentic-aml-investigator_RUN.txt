agentic-aml-investigator — how to run
=====================================

A multi-agent AML/fraud investigation system (LangGraph + Claude) over
synthetic data. All data is fake; nothing real is used.

Requirements
------------
- Python 3.10 or newer
- An Anthropic API key (starts with sk-ant-). Get one at console.anthropic.com
  -> Settings -> API Keys. A Claude Pro subscription does NOT include this;
  the API is billed separately, pay-per-token (cents for this project).


Setup
-----
1. Open a terminal in this folder.

2. (Optional but recommended) create a virtual environment:

   Windows (PowerShell):
       py -m venv .venv
       .\.venv\Scripts\Activate.ps1

   macOS / Linux:
       python3 -m venv .venv
       source .venv/bin/activate

3. Install dependencies:
       pip install -r requirements.txt

4. Add your API key:
   - Copy .env.example to .env
     Windows:  copy .env.example .env
     mac/Linux: cp .env.example .env
   - Open .env and paste your key after ANTHROPIC_API_KEY=


Build the data and model (no API key needed for these two steps)
----------------------------------------------------------------
5. Generate the synthetic dataset:
       python data/generate_data.py

6. Train the risk scorer:
       python models/train_scorer.py


Run it
------
7. Launch the web UI:
       streamlit run app.py

   Pick a flagged transaction, click Investigate, and watch the agents work.

   Or run one case from the terminal instead:
       python run_cli.py                 (grabs one from the review queue)
       python run_cli.py TXN000123       (a specific transaction)


Notes
-----
- Steps 5 and 6 run fully offline. Only the agent run (UI / CLI) calls Claude,
  because the planner, narrative, and reviewer use the LLM.
- If the app says "no data" or "no model", you skipped step 5 or 6.
- To switch model provider, edit .env (LLM_PROVIDER=anthropic is the default).
- The file system resets nothing on your machine; data/ and models/ artifacts
  are regenerated by steps 5-6 and are gitignored.
